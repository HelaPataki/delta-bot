# Прогонка delta-bot: всплеск объёма + дельта

Период: с 2025-01-01, 4h-свечи USDT-перпетуалов Binance.
Фильтры для всех групп: оборот свечи ≥ $50,000, капитализация $10M–$400M (оценка).
Всплеск объёма = оборот свечи / медиана оборота 12 предыдущих свечей.
Монет с капитализацией: 635; без капитализации (пропущены): 288.

Уровни считаются от цены закрытия сигнальной свечи по high/low следующих 60 свечей (10 дней).
