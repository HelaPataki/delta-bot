# delta-bot

Идея: ловить 4h-свечи USDT-перпетуалов Binance со всплеском объёма (x3/x5/x10 к медиане 12 предыдущих свечей)
и сильным перекосом дельты (дельта % = (покупки − продажи) / объём свечи × 100, порог ±17%).

## Историческая прогонка

Actions → **History run** → **Run workflow**. Параметры: порог дельты, минимальный оборот свечи, начало периода.

Результаты появляются в папке `results/`:
- `summary.md` — сводка: сколько сигналов, как часто цена доходила до ±4/10/20% за 10 дней и на какой день, сравнение с обычными свечами (baseline);
- `history_signals.csv` — все сигналы по строкам (время по Киеву).

Данные: архив Binance (data.binance.vision), капитализация — CoinGecko
(на момент свечи оценивается как текущая капитализация × цена тогда / цена сейчас).

## POC сигнальной свечи

Actions → **POC run** → **Run workflow** (после History run). Берёт `results/history_signals.csv`,
по минутным свечам Binance находит POC (цену минутки с наибольшим объёмом) каждой сигнальной свечи
и пишет `results/poc_signals.csv` и `results/poc_summary.md`.
